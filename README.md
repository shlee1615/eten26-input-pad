# 倚天26輸入便箋

適合需要用倚天26打中文、又不方便在原程式使用系統輸入法的 Mac 使用者。在小視窗輸入中文，再複製、返回原程式，或一鍵貼回原欄位。

以 [McBopomofoWeb](https://github.com/openvanilla/McBopomofoWeb) 2.1.0 的注音引擎為核心，使用 Swift、AppKit 與 WKWebView 封裝。這是獨立的社群工具，感謝小麥注音作者與字型作者的開源成果。

![便箋視窗及返回後置頂狀態](docs/input-pad.png)

## 下載與安裝

請到 [Releases](https://github.com/shlee1615/eten26-input-pad/releases/latest) 下載 `eten26-input-pad-1.4.0-macos-arm64.zip`。此預編譯版本需要 **Apple Silicon Mac（M 系列）、macOS 13 或更新版本**；實際測試環境為 macOS 26.4。不提供 Intel 或 Windows 執行檔。

1. 解壓縮，將「倚天26輸入便箋.app」移到自己的「應用程式」資料夾，再開啟。
2. Mac 輸入來源選 **ABC**；使用 Chrome 遠端桌面時，Windows 端也選英文。
3. 在便箋用倚天26鍵輸入。例如「揮」按 `h x q`，再按 **空白鍵**完成一聲，最後按 Enter 確定。

目前 app 使用本機 ad-hoc 簽章，尚未經 Developer ID 簽章及 Apple 公證。macOS 可能阻擋首次開啟；請核對下載來源及 `SHA256SUMS.txt`，再依 [Apple 的開啟說明](https://support.apple.com/zh-tw/102445) 決定是否允許開啟。

## 功能

- 預設倚天26；也可切換標準注音等原引擎支援的鍵盤配置。
- 自動／手動選字、繁簡、全半形標點、候選鍵與數量、游標行為、聲調及其他輸入選項。
- 自訂詞、排除詞、四款內建離線注音／拼音字型。
- 視窗置頂可開關；縮小或關閉視窗後，點選單列的鍵盤圖示即可叫回。
- 複製、復原與重做；前兩種模式保留草稿；Enter 模式在確認貼上且內容未變更後清除已送回文字。

| 操作 | 做什麼 | 輔助使用權限 |
| --- | --- | --- |
| 複製 | 複製文字，自行切換程式貼上 | 不需要 |
| 複製並返回 | 自行複製並切回原程式；再按 ⌘ V 貼上 | 不需要 |
| 一鍵送回原欄位（按鈕「複製並貼回」） | 自行複製、返回、恢復原欄位／游標並貼上一次 | 需要 |
| Enter 貼回原欄位 | 中文輸入完成後按 Enter，放開按鍵即貼回；視窗使用較矮的單行區 | 需要 |

先在目標程式點好輸入欄位，再點便箋或選單列圖示。選好送回模式後，點右側按鈕或按 **⌘ Shift Enter**；不用先按「複製」。**⌘ Enter** 只複製，**⌘ ,** 開啟設定。

Enter 模式中，候選選字、標記及其他選單的 Enter 維持原操作；選字後再按一次 Enter 才貼回。未完成注音會留在便箋，Shift Enter 只確認輸入。既有多行草稿仍保留。貼上失敗、結果未確認或期間已輸入新內容，都保留草稿，不會自動重送。

一鍵與 Enter 模式請在「系統設定 → 隱私權與安全性 → 輔助使用」授權此 app，然後重新點好原欄位再回便箋。不需要重開機。更新或自行重建後若權限失效，請移除舊項目，重新加入實際使用的 app；重新選好原欄位後再試。

開啟置頂時，成功返回後便箋仍保持最上層，鍵盤焦點留在原程式。它只貼入文字，**不代按 Enter、不送出表單**。無法可靠辨識原欄位、欄位內容已變更或無法確認貼上時，會顯示原因；請查看原欄位，避免重複貼上，也可改用「複製並返回」。各程式的輔助使用支援不同，不能保證所有欄位都支援一鍵模式。

## 資料與已知限制

注音解析、詞庫與選字在本機執行，不傳送輸入內容。工具不要求輸入監控權限。自動返回僅使用輔助使用焦點／選取通知、欄位摘要與貼上操作，不記錄欄位原文，不向密碼欄位送回。

設定與自訂詞庫存於 `~/Library/Application Support/倚天26輸入便箋/settings.json`；置頂／送回模式存在 macOS 偏好設定。草稿只留在記憶體，結束程式前請自行保存。複製與送回會改變系統剪貼簿。

- 一聲必須以空白鍵完成；尚未完成聲調就按 Enter 會顯示提示。複製及前兩種送回模式會原樣保留未完成注音，不自動猜測聲調；Enter 模式須先完成注音。
- 倚天26的獨立 `ㄝˋ`／`ㄟˋ` 與 `ㄘˋ`／`ㄗˋ` 共鍵；`wk`／`qk` 會解成後兩者。需要前兩種讀音時，可暫切標準注音。
- 這是輸入便箋，需在便箋視窗中打字，不是 macOS 系統輸入法或「便箋」App 外掛。

完整操作說明：[使用說明](input-pad/使用說明.txt)。

## 原始碼與重建

Releases 的 `eten26-input-pad-1.4.0-source.zip` 含便箋原始碼、字型及授權。Git 儲存庫不存放大型字型與引擎產物；重建前先取得固定版本的公開依賴並套用引擎補丁：

```sh
python3 scripts/prepare.py
zsh input-pad/build.sh
```

需要 macOS、Xcode Command Line Tools（Swift 與 macOS SDK）；從 Git checkout 取得並重建原引擎時另需 Node.js／npm。產物為 `build/倚天26輸入便箋.app`。不會自動取代已安裝版本。建置腳本會重新編譯引擎，並將 Swift 最低部署版本指定為 macOS 13；架構依建置機器而定。

原引擎固定在 `e7bfa5547b92e08265bff2b23ecf0ada832d9270`，本專案套用 [狀態分類補丁](patches/engine-state-kind.patch)，讓正式壓縮後的引擎也可可靠判斷 Enter 狀態。字型固定版本及 SHA-256 記於 [prepare.py](scripts/prepare.py)。

## 驗證

```sh
zsh scripts/test.sh
```

1.4.0 發布前：77 項 JavaScript 測試、27 項 Swift 送回情境、12 項欄位／游標政策檢查及設定儲存測試通過。第三模式視窗、候選列與多行草稿已本機檢查；跨程式自動貼上不列為此次已驗證項目。

`node input-pad/input-audit.cjs` 可掃描原詞庫中的 1,377 個有漢字候選的單音節，涵蓋標準／倚天26與自動／手動四種組合。標準配置全數通過；倚天26保留上述兩項共鍵歧義，完整掃描會回報它們並以非零狀態結束。
